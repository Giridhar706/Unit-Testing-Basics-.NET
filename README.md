# CalculatorSolution

# 🧮 Calculator with Unit Testing (.NET)

## 📌 Overview

This project implements a simple calculator using C# with basic arithmetic operations.
Unit testing is performed using MSTest to verify correctness and handle edge cases.

---

## 🚀 Features

* Addition, Subtraction, Multiplication, Division
* Exception handling for division by zero
* Unit testing using MSTest
* Validation using assertions

---

## 🛠️ Technologies Used

* C#
* .NET
* MSTest Framework

---

## 📁 Project Structure

CalculatorSolution/
│
├── CalculatorLibrary
│   └── Calculator.cs
│
├── CalculatorTests
│   └── Test1.cs

---

## ▶️ How to Run

1. Open solution in Visual Studio
2. Build the project
3. Go to Test → Test Explorer
4. Click Run All

---

## ✅ Output

All test cases pass successfully in Test Explorer.
